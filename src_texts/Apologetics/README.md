# Apologetics sources

Public-domain works kept for reference beside `data/apologetics.json`.
Where each came from, and its checksum, is in `SOURCE`.

Each is kept as text where a text is available. The two Robert Roberts
books exist only as scans, so their text is the scans' OCR, which has
errors; the scans are kept too, in Git LFS (`git lfs pull` fetches them).

| File | Work | Public domain because |
|---|---|---|
| `morison-who-moved-the-stone.txt` | Frank Morison, *Who Moved the Stone?* (1930), from a modern typeset of the 1930 text | Published 1930 (US); author died 1950 (UK, life + 70) |
| `greenleaf-testimony-of-the-evangelists.txt` | Simon Greenleaf, *An Examination of the Testimony of the Four Evangelists* (1846), Project Gutenberg #34989 | Published 1846 |
| `paley-evidences-of-christianity.txt` | William Paley, *A View of the Evidences of Christianity* (1794), Project Gutenberg #14780 | Published 1794 |
| `roberts-christendom-astray-1884.pdf`, `.txt` | Robert Roberts, *Christendom Astray from the Bible* (1884): scan and OCR | Author died 1898 |
| `roberts-the-trial-1908.pdf`, `.txt` | Robert Roberts, *The Trial: Did Christ rise from the dead?* (1908 edition; first 1882): scan and OCR | Author died 1898 |
| `tacitus-annals-church-brodribb.txt` | Tacitus, *Annals*, tr. A. J. Church and W. J. Brodribb (1876), from English Wikisource | Translators died 1912 and 1905 |
| `josephus-antiquities-whiston.txt` | Josephus, *Antiquities of the Jews*, tr. William Whiston (1737), Project Gutenberg #2848 | Published 1737 |
| `pliny-letters-melmoth.txt` | Pliny the Younger, *Letters*, tr. William Melmoth, rev. F. C. T. Bosanquet, Project Gutenberg #2811 | Translators died 1799 and 1918 |
| `darwin-origin-of-species-1859.txt` | Charles Darwin, *On the Origin of Species* (1859, first edition), Project Gutenberg #1228 | Published 1859; author died 1882 |

The Project Gutenberg files keep the Gutenberg licence header and footer,
as that licence requires when redistributing them with the name.

Works still under copyright, such as Lee Strobel's *The Case for Christ*
and Ron Abel's *Wrested Scriptures*, are not kept here.
