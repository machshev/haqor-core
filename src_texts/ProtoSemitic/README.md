# Proto-Semitic root derivations

Adam Anderson and Jason Moser, *Protosemitic Root Derivations* (Zenodo,
2024), <https://doi.org/10.5281/zenodo.14160276>, licensed Creative Commons
Attribution 4.0 International. Fetched by `scripts/fetch-protosemitic-roots.sh`.

`SemiticRootDerivations.csv` links a Proto-Semitic root (`PS-root`, with its
Wikidata lexeme `PS_Lid`) to an entry descended from it (`lang_to`,
`entry_to_id`, `entry_to` as `form[gloss]POS`) in Akkadian, Arabic, Aramaic,
Ge'ez, Hebrew, Punic or Ugaritic, with the Akkadian root and its Wikidata
lexeme where there is one.

The authors describe many of the derivations as a working hypothesis. The Haqor
lexicon's briefs use them as leads to cognates (ADR 7), which an entry cites
from each language's own dictionary.
